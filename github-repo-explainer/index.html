📦 GitHub Repo Explainer

Local GenAI mini project — paste a GitHub URL, get a simple-language explanation of the codebase.

Python FastAPI Streamlit Hugging Face Local LLM

❓ What it does

Enter https://github.com/username/repository. The app clones the repo locally, extracts source files, sends the code to a locally running LLM, and shows a beginner-friendly explanation.

GitHub URL→Clone (GitPython)→Extract code→Local LLM→FastAPI→Streamlit UI

▶️ How to run (local demo)

  1. Install deps: pip install -r requirements.txt
  2. Terminal 1 — backend: cd backend then python -m uvicorn main:app --host 127.0.0.1 --port 8000
  3. Terminal 2 — frontend: python -m streamlit run frontend/app.py
  4. Open http://localhost:8501, paste a repo URL, click Explain.

First explanation takes 30–90s (model loads on CPU). Tested with pypa/sampleproject and DIPINROKA10/Gen_AI_W.

Project Overview
This project (Gen_AI_W) is a Generative AI experiment lab. It teaches models to create new content such as images.

The application allows users to:
- Run neural style transfer experiments
- Train/test GAN-style image generation (e.g. CycleGAN)
- Experiment with diffusion models
- Explore transformers and attention

Main Technologies:
- Python

How it works:
User opens the scripts → scripts load data and define the model → code runs locally in Python → results are produced from the learned model.
